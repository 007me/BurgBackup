# Support policy

Burg Backup is distributed free of charge as a community freeware project.

## Best-effort only

There is **no commercial support contract, SLA, guaranteed response time, guaranteed bug-fix schedule, guaranteed compatibility commitment or commitment to continue development**.

Users remain responsible for validating that backups and restores work in their own environment.

## Where to ask or report

- Use **GitHub Issues** for reproducible bugs.
- Use **GitHub Discussions** for usage questions and general ideas, if Discussions is enabled for the repository.
- Use the repository's **private vulnerability reporting** mechanism for security issues. Do not disclose security vulnerabilities publicly before they can be reviewed.

A report may be reviewed, answered, fixed, deferred or closed at the maintainer's discretion.

## Before reporting a backup problem

Please include:

- Burg Backup version.
- Windows version.
- Backup job type: SFTP or UNC/SMB/NAS.
- Whether the problem occurs in a manual or scheduled run.
- The relevant log excerpt, with sensitive information removed.
- Clear steps to reproduce the problem.

Do **not** post repository passwords, SMTP passwords, SMB passwords, private SSH keys, personal files, customer information or other secrets.

## No data-recovery service

The maintainer does not provide a data-recovery service and cannot guarantee recovery of lost or damaged data. Periodic restore testing is part of operating any backup solution safely.
